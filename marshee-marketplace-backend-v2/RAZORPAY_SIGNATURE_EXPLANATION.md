# Razorpay Signature Explained

## What is `razorpay_signature`?

`razorpay_signature` is a **security hash** generated by Razorpay after payment completion. It's used to verify that the payment response is authentic and hasn't been tampered with.

---

## How Razorpay Generates the Signature

### Formula:
```
signature = HMAC-SHA256(orderId + "|" + paymentId, YOUR_SECRET_KEY)
```

### Step-by-Step:
1. Razorpay takes your `orderId` (or `payment_link_id`)
2. Razorpay takes the `payment_id` generated after payment
3. Concatenates them with a pipe: `"plink_xxx|pay_yyy"`
4. Creates HMAC SHA256 hash using your Razorpay Secret Key
5. Returns this hash as `razorpay_signature`

### Example:
```javascript
orderId = "plink_RntkVxBHS7QYZM"
paymentId = "pay_LP1234567890"
secretKey = "your_razorpay_secret_key" // From your .env

// Razorpay does:
const text = "plink_RntkVxBHS7QYZM|pay_LP1234567890";
const signature = crypto
  .createHmac('sha256', secretKey)
  .update(text)
  .digest('hex');
// Result: "a1b2c3d4e5f6789..." (long hexadecimal string)
```

---

## When is it Available?

### ❌ NOT Available Initially
- When order is created (your current order document)
- When payment link is generated
- Before user completes payment

**Your order shows:** `"status": "pending"` → Payment not completed yet

### ✅ Available After Payment
- When user completes payment on Razorpay page
- Razorpay redirects to your `callbackUrl` with signature
- Sent as a URL query parameter

---

## Where to Get It?

### From Razorpay Callback URL

After user completes payment, Razorpay redirects to:
```
https://www.marshee.com/payment/status?
  razorpay_payment_link_id=plink_RntkVxBHS7QYZM&
  razorpay_payment_id=pay_LP1234567890&
  razorpay_signature=a1b2c3d4e5f6789abcdef...&  ← EXTRACT THIS!
  razorpay_order_id=order_xxx
```

### Frontend Code to Extract:

```javascript
// On your callback page (e.g., /payment/status)
const urlParams = new URLSearchParams(window.location.search);

// Get signature from URL
const razorpay_signature = urlParams.get('razorpay_signature');
const razorpay_payment_id = urlParams.get('razorpay_payment_id');
const razorpay_order_id = urlParams.get('razorpay_order_id') || 
                          urlParams.get('razorpay_payment_link_id');

console.log('Signature:', razorpay_signature);
// Output: "a1b2c3d4e5f6789abcdef..." (long hex string)
```

## How Verification Works

### Your Backend Verifies It:

```javascript
// In razorpayService.js (line 136-142)
const text = `${orderId}|${paymentId}`;
const generatedSignature = crypto
  .createHmac('sha256', YOUR_SECRET_KEY)  // Same secret Razorpay used
  .update(text)
  .digest('hex');

// Compare with signature from Razorpay
const isValid = generatedSignature === razorpay_signature;
```

### Why This Works:
1. ✅ Razorpay generates signature using your secret key
2. ✅ Your backend regenerates signature using same secret key
3. ✅ If signatures match → Payment is authentic ✅
4. ✅ If signatures don't match → Payment might be tampered ❌

## Complete Flow

### 1. Order Created (Current State)
```
✅ Order created in database
✅ Payment link: plink_RntkVxBHS7QYZM
✅ Checkout URL: https://rzp.io/rzp/aUdQSmTh
❌ Signature: NOT YET (payment pending)
```

### 2. User Clicks Payment Link
```
User → Opens https://rzp.io/rzp/aUdQSmTh
User → Completes payment on Razorpay page
```

### 3. Razorpay Redirects (After Payment)
```
Razorpay → Redirects to callbackUrl with:
  ✅ razorpay_payment_id = "pay_xxxxx"
  ✅ razorpay_signature = "a1b2c3d4e5f6..."  ← NOW AVAILABLE!
  ✅ razorpay_order_id = "plink_RntkVxBHS7QYZM"
```

### 4. Your Frontend Receives It
```javascript
// Extract from URL
const signature = urlParams.get('razorpay_signature');
// Now you have it!
```

### 5. Verify Payment
```javascript
POST /api/v1/payments/razorpay/verify
{
  "razorpay_order_id": "plink_RntkVxBHS7QYZM",
  "razorpay_payment_id": "pay_xxxxx",
  "razorpay_signature": "a1b2c3d4e5f6..."  // ← Use signature from URL
}
```

## Important Notes

### 1. **Security Purpose**
- Prevents payment tampering
- Ensures payment data authenticity
- Verifies payment came from Razorpay

### 2. **Never Store in Order Initially**
- Signature is only available after payment
- Don't try to generate it yourself
- Only Razorpay can generate valid signatures

### 3. **Format**
- Hexadecimal string (0-9, a-f)
- Typically 64 characters long
- Example: `"a1b2c3d4e5f6789abcdef1234567890abcdef1234567890abcdef1234567890"`

### 4. **Storage**
- After verification, you might want to store it
- Can be saved in `paymentAttempts` array
- Useful for audit trail
